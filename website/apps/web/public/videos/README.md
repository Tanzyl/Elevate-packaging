# Hero background video

Drop a file named **`hero.mp4`** in this folder and the homepage hero will auto-use it as a full-bleed background (object-cover, muted, looped, autoplay, playsInline).

If the file is missing or fails to load, the hero falls back to the animated image + film-line pattern + foil shine.

## Recommendations

- **Format**: MP4 (H.264) + optionally a WebM for better compression
- **Resolution**: 1920×1080 minimum; 3840×2160 ideal for retina
- **Duration**: 12–25 seconds, loops cleanly
- **File size**: under 8 MB (target 3–5 MB for a 15s clip; use HandBrake or ffmpeg)
- **Content**: packaging production line, extrusion, printing press, pouch forming, metallized film close-up
- **No audio** — it's muted and will be stripped anyway

## Sources that allow commercial use

- [pexels.com/videos](https://www.pexels.com/videos/) — search "factory", "conveyor belt", "production line"
- [coverr.co](https://coverr.co/) — curated free loops
- [mixkit.co](https://mixkit.co/free-stock-video/) — free stock
- [pixabay.com/videos](https://pixabay.com/videos/) — free stock

Confirm the license before shipping to production — some clips require attribution.
